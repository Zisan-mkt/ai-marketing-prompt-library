# AI Marketing Prompt Library

A practical, beginner-friendly collection of 43 reusable prompts for SEO, AEO/GEO, social media, branding, B2B lead generation, and campaign strategy.

## Project purpose
This library helps marketers use AI as a structured assistant for planning, drafting, analysis, and quality assurance. It is designed as a portfolio project: each prompt includes a clear use case and placeholders to customize.

## Contents
- `README.md` — project overview and usage instructions
- `prompts.md` — complete prompt library
- `prompt_examples.md` — worked examples using fictional business data
- `TESTING_LOG.md` — validation checklist and space to record test results
- `LICENSE` — MIT license for the original prompt text

## How to use
1. Choose a prompt that matches your task.
2. Replace every bracketed placeholder such as `[AUDIENCE]` with your information.
3. Give the model accurate source material and constraints.
4. Review the response for factual accuracy, brand fit, privacy, and compliance.
5. Iterate with a specific follow-up instruction.
6. For important work, verify claims with trusted sources and measure results.

## Important note on testing
These prompts are structured and include quality controls, but AI output varies by model, input quality, and context. Do not describe a prompt as empirically validated until you have run it, reviewed the output, and recorded the results in `TESTING_LOG.md`. The example outputs in this repository are illustrative demonstrations, not performance claims.

## Responsible use
- Do not upload confidential employer, client, or customer information.
- Do not paste passwords, API keys, personal data, or private sales records into AI tools.
- Verify claims, citations, legal requirements, current platform specifications, and product capabilities.
- Obtain permission before publishing client work, logos, or proprietary assets.
- This library is educational and does not guarantee rankings, leads, or campaign outcomes.
